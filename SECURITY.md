# Security policy

Please report suspected vulnerabilities privately to the maintainer at
[stefano@natangelo.dev](mailto:stefano@natangelo.dev). If GitHub private
vulnerability reporting is available, you may also use that channel.

Include the affected plugin and OJS versions, a description of the issue,
and reproducible steps using synthetic data where possible. Do not include
credentials, private manuscripts, or other confidential information.

Please avoid opening public issues containing exploitable details before
the maintainer has had an opportunity to investigate. Ordinary bug reports
and feature requests can be submitted through GitHub Issues.
